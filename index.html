Privacy Policy – SaveToMake

SaveToMake is a personal finance planning and savings tracking application.

The application is operated by Bodó Bálint.

Contact: bobalint2003@gmail.com

1. Data We Collect

We may collect and process the following types of data:

Account Data

  • Email address
  • Authentication-related data
  • Name

Profile Data

  • Preferred currency
  • User settings and preferences

Financial Data

  • Transactions
  • Balances
  • Savings
  • Assets
  • Financial goals and milestones
  • Alerts and planning-related data

Technical Data

  • Login session information
  • Locally stored email address
  • Notification preferences

2. How We Use Data

  • To create and manage user accounts
  • To provide the core functionality of the application
  • To display financial summaries, goals, and alerts
  • To apply user-selected currency preferences
  • To send local notifications (e.g. reminders and savings tips)

3. Service Providers and Third Parties

  • Supabase – authentication and database services
  • CoinGecko, Yahoo Finance, Frankfurter – market prices and exchange rate data

These services are required for the proper operation of the application.

User financial data entered in the app is not made publicly available.

4. Data Sharing

  • We do not sell personal data
  • We only share data with service providers necessary to operate the application

5. Data Retention

  • We retain account-related data as long as the account is active
  • Data is deleted upon user request
  • Certain data may be retained for a limited period if required for legal, security, or fraud-prevention purposes

6. Account and Data Deletion

Users can request account deletion within the application.

To request account deletion, please send an email to:

bobalint2003@gmail.com

Your data will be deleted within 7 days.

7. Data Security

  • Data is transmitted over secure (HTTPS) connections
  • Authentication and storage are handled via Supabase infrastructure
